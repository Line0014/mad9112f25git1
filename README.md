# Website 4 Git

A small website that lists the core Git commands I practised in MAD9112.

## Commands covered

- `git init`: creates a new repository.
- `git add -A`: stages all changes.
- `git commit -m "message"`: saves staged changes as a commit.

## Example

```bash
git add -A
git commit -m "Add descriptions"
git push
```
