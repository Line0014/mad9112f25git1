Git Commands

  • git init: Creates a new local Git repository in the current folder.
  • git status: Shows which files are changed, staged, or untracked.
  • git add -A: Stages all new, changed, and deleted files for the next commit.
  • git commit -m "message": Saves the staged changes as a commit with a message describing them.
  • git log: Lists the commit history, showing each commit's hash, author, date, and message.
  • git remote add origin <url>: Connects your local repository to a remote repository on GitHub.
  • git push: Uploads your local commits to the remote repository.
  • git pull: Downloads and merges the latest commits from the remote repository.
  • git clone <url>: Copies an entire remote repository to your computer.
  • git branch: Lists your branches, or creates and switches between them.
